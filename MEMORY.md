## Decisions

- Astro static output (not SSR); no Cloudflare adapter.
- `cf dev` is the local server; `astro build` is the production build;
  `wrangler deploy --config wrangler.deploy.jsonc` is the deploy command.
- `cf build` / `cf deploy` need a Build Output Specification that pure static
  Astro does not emit. Revisit when the beta CLI supports static outputs.
- The autogenerated `wrangler.jsonc` (name `example`, @astrojs/cloudflare
  entrypoint) was moved to `/tmp/opencode/wrangler.autoconfig.jsonc`; it broke
  the static deploy. The active deploy config is `wrangler.deploy.jsonc`,
  passed with `--config`. `@astrojs/cloudflare` remains unused.
- Wrangler is authenticated via OAuth as `cramirezmun@unal.edu.co`; the
  `carlosramirez.app` zone and `portfolio` Worker belong to that account.
- The old root site on the domain was replaced by the Astro `dist`; only the
  apex custom domain is configured (`www` intentionally not enabled).
- Portrait is the supplied photo; `PortraitFrame` falls back to a placeholder
  if the file is removed.
- Project galleries live in `src/data/projects.ts` under `gallery`; the card
  uses the first available image, the detail page renders the full gallery.
- Wide 16:9 posters (CyclingSafety) set `fit: 'contain'` so edge labels are not
  cropped; UI screenshots use the default `cover` fit.
- CicloMart's `itemContainer.desktop.items` is 5. Headless Chrome reported an
  800px `window.screen.width`, so `react-multi-carousel` picked the 2-item
  tablet breakpoint. Captures now emulate `screenWidth=1600`, and the retaken
  screenshots show five cards.
- CicloMart captures were generated from the `tweaks` seed
  (`dbCreationForCleverCloud.sql`) through a local `{results}` mock API, because
  `main`'s `dbInserts.sql` is empty and the live site is unreachable.
- CourseClash duel capture uses a temporary `/duel-preview` route in the clone
  with the real duel components plus mock ELO/categories/challenge; the real
  `/duelos` route is SSR + auth-gated.
- The 20 MB academic paper was compressed with Ghostscript `/ebook` to 1.5 MB
  and deployed at `public/docs/CyclingSafety.pdf`; it is Spanish only and the
  link label says so in both languages.
- The 20 MB original PDF is kept at `/tmp/opencode/CyclingSafety.pdf`; the
  temporary capture/source PNGs were removed.
- CV buttons use locale-specific paths: `/cv/carlos-ramirez-cv.pdf` (EN) and
  `/cv/carlos-ramirez-cv-es.pdf` (ES), each checked with `publicFileExists`.
- Social links kept: GitHub, LinkedIn, email, WhatsApp, TikTok, YouTube.
- Formatted project IA: 3 featured rows on the homepage + `/projects/` and
  `/es/proyectos/` archive pages.
- Design: dark engineering/editorial, orange signal color, Space Grotesk +
  IBM Plex Mono, instrumentation/blueprint diagrams.
- SVG patterns use `fill="none"` on open paths (prevents accidental black
  triangle fills / diagonal hatching).
